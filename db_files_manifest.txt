# Minimal set of converted reference-database files needed to run vgan
# (haplocart / euka / soibean / trailmix) against vg v1.75.
#
# All paths are relative to the vgan repo root.
#
# TOTAL SIZE: ~11.5 GB (apparent/logical size - this is what Google Drive will
# actually store/transfer). Several of these files (euka_db.dist, euka_db.og,
# euka_db.min, euka_db.gbwt, euka_db.gg, euka_db.giraffe.gbz, soibean_db.og,
# graph.og, graph.xg, hcfiles/graph.og) are SPARSE on this filesystem -
# `du` reports a much smaller number (~2.7 GB combined) because it only
# counts disk blocks actually allocated, but that's not what matters here:
# a normal file read (which is what any cloud upload/sync client does)
# returns the full logical content including the zero-filled holes, so the
# real upload size is the apparent size (`ls -l` / `stat`), not `du`. If
# staging these locally before uploading, use `cp --sparse=always` or
# `rsync -S` to keep them sparse and save local disk/time - that has no
# effect on how much the actual Google Drive upload consumes, though.
#
# Excluded on purpose (do NOT need to upload these):
#   - *.odgi.bak / *.old.bak / *.v1022.bak   (pre-conversion backups)
#   - *.shortread.withzip.min / *.shortread.zipcodes
#       (giraffe's own runtime-rebuilt minimizer cache - unsafe to reuse
#       across machines/process invocations, must regenerate fresh on
#       whatever machine actually runs vgan; see MIGRATION.txt)
#   - soibean_db.gbwt / .gg / .gfa / .dist / .min / .giraffe.gbz
#       (~23 GB, built as an early sanity check but never actually read by
#       make_graph_files.sh or soibean's classification workflow)
#   - share/vgan/tmfiles/pub.graph.*
#       (stale leftovers; the real pub.graph set lives in its own
#       publication_tmfiles/ directory with its own matching haps.treefile -
#       mixing them back into tmfiles/ caused a real MCMC crash, see
#       MIGRATION.txt section D.5, bug #7)
#
# Lines starting with '#' and blank lines are comments/separators - strip
# them if feeding this into `tar -T` / `rsync --files-from=`, e.g.:
#   grep -v '^#' db_files_manifest.txt | grep -v '^$' > db_files_manifest.clean.txt
